# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security issue or vulnerability in this plugin (especially regarding credential handling, secret leakage, or unauthorized token exposure), please report it responsibly:

1. **Do not** file a public GitHub issue.
2. Open a private security advisory via GitHub Security Advisories or contact the maintainer directly.
3. Include details of the vulnerability, affected components, and steps to reproduce.
